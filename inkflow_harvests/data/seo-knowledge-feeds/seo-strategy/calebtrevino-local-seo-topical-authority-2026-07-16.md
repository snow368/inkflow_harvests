# 本地 SEO 主题权威建设框架

## Summary
基于 25+ 本地网站建设经验，Caleb Trevino 总结出 Google 主题权威建设的完整框架：证明你提供服务 + 理解服务相关问题 + 深度覆盖目标城市。

## Key Takeaways
1. **主题权威核心三要素**：
   - 你提供服务
   - 你理解服务相关问题
   - 你深度覆盖目标城市
2. **执行清单**：
   - 高价值关键词创建独立服务页
   - 城市页绑定到确切服务
   - FAQ 页面含详细回答
   - 内链引向高价值页 + 首页
   - GBP 和网站说同样的服务内容（+ NAP一致性）
   - 评论强化服务 + 地点
   - 本地外链
   - 每页包含独特实体
3. **AI引用**：Google AI Overviews + ChatGPT 从这些页面提取内容

## Apply to Skills
- `seo-content-writer`：每页都需要独特实体 + FAQ + 本地化内容
- `seo-topic-cluster`：服务页做 Pillar，城市页做 Cluster
- `seo-internal-linking`：内链定向引向高价值+首页
- `seo-backlink-audit`：本地外链（GBP/本地目录）
