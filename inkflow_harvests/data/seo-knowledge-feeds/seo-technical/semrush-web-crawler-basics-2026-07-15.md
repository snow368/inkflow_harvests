# Web Crawler 搜索引擎爬虫基础

## Summary
Semrush 科普：Web Crawler 是访问和处理网页以理解其内容的机器人。搜索引擎用爬虫发现和分类网页，网站所有者也可用爬虫工具监控和优化。

## Key Takeaways
1. **爬虫别名**：Crawlers / Bots / Spiders / Spiderbots
2. **用途**：
   - 搜索引擎：发现 + 分类网页
   - 网站所有者：外链爬虫 / 技术审计爬虫 → 监控性能、分析竞品、优化SEO
3. **技术相关**：Crawlability 直接影响索引效率和排名

## Apply to Skills
- `seo-technical-check`：Crawlability 检查项（可爬取性/可索引性）
- `seo-sitemap-config`：Sitemap 提高爬虫发现效率
