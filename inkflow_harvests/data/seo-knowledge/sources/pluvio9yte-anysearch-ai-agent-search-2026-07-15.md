# AnySearch — AI Agent 搜索基础设施

## Summary
Parallel/Perplexity/Tavily 等搜索工具给 Agent 使用时的问题是：只返回链接+摘要，Agent 还要自己点开筛选。AnySearch 是专为 Agent 设计的搜索 Skill，直接输出结构化 Markdown。

## Key Takeaways
1. **问题**：通用搜索工具返回非结构化结果，Agent 需要额外解析/筛选
2. **AnySearch 能力**：
   - 实时网页搜索
   - 垂直领域搜索（金融/学术/代码/社媒）
   - 网页→干净 Markdown（extract）
   - 结构化输出，Agent 直接可用
3. **启示**：搜索 + 提取 + 结构化是 AI 时代的搜索基础设施

- `seo-technical-check`：爬取/解析层面的技术优化参考
