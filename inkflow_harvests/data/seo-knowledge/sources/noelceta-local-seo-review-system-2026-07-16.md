# Local SEO Review 规模化生成系统

## Summary
大多数本地商家每月自然获得 1-2 条评价。Noel 建立了一个每月产生 8-15 条评价的规模化系统框架。

## Key Takeaways
1. **核心问题**：Review 是本地 SEO 的瓶颈
2. **规模化的关键**：将评价获取从被动（等用户写）转为主动（系统化流程）
3. 对本地 SEO 排名因子：Review 数量 + 质量 + 多样性直接影响本地 Pack 排名

## Apply to Skills
- `seo-competitor-gap`：本地SEO竞品分析时可纳入Review指标对比
- `seo-content-writer`：可引导客户写有内容的Review（结构化引导）
