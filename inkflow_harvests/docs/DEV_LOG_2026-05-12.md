## Scraper 使用方法

```bash
# 先启动 Chrome（必须！）
# Windows: "C:\Program Files\Google\Chrome\Application\chrome.exe" --remote-debugging-port=9222

# JSON 城市列表
python scripts/python_scraper.py --state WA --cities '["Seattle","Tacoma"]'

# 全量城市文件
python scripts/python_scraper.py --state WA --cities-file scripts/wa_cities.txt

# 断点续跑
python scripts/python_scraper.py --state WA --cities-file scripts/wa_cities.txt --start-from-city Bellevue

# 自启动模式（无 CDP 时，稳定性较差）
python scripts/python_scraper.py --state WA --cities-file scripts/wa_cities.txt --cdp-url ''
```

输出路径：`./data/scrape_output/WA_Raw.csv`, `WA_Live_Scrape_View.csv`, `WA_scanned_cities.log`
