# Lighting Library — 光线库

每种光线的详细描述（中文画面语言，可直接用于 prompt）。

## LT01 — 侧逆金属光（Rim Light）
```
描述：单侧光源从侧后方45°打来，在金色铜环边缘勾勒出锐利的高光线，
金属表面反射出镜面光泽，暗部保留细腻纹理过渡，
产品轮廓与黑色背景被光带清晰分离
效果：立体感强，金属质感突出，高级感
适用：墨盒悬浮展示、金属环细节
```

## LT02 — 柔光箱顶光（Softbox Top）
```
描述：柔光箱从正上方45°均匀打光，阴影柔和过渡无硬边，
半透明外壳在光线下呈温润的漫散射效果，
内部弹簧结构若隐若现，高光柔和不刺眼
效果：柔和、均匀、自然
适用：电商首图、套装陈列
```

## LT03 — 硬质侧光（Hard Side）
```
描述：单一强光源从侧面打来，产品一侧被高光照亮，
另一侧落入深邃阴影，明暗交界线锐利清晰，
金属表面反射出针尖般的耀眼光点
效果：高对比、戏剧性、力量感
适用：强调产品轮廓、个性风格
```

## LT04 — 背光透射（Backlight Translucent）
```
描述：光源从产品后方穿透半透明外壳，
白色磨砂壳体均匀发光，边缘透出暖色光晕，
内部弹簧和针管的剪影清晰可见
效果：科技感、透视感、精密
适用：半透明外壳产品、展示内部结构
```

## LT05 — 双灯交叉（Cross Light）
```
描述：两盏灯从左右45°对称打来，在中线交汇，
产品被均匀照亮无死区，阴影分散在两侧，
金属部分反射出两条平行高光线
效果：均匀无死角，细节完整
适用：墨盒整体展示、多角度细节
```

## LT06 — 底部透光（Bottom Up）
```
描述：光源从产品下方透射，在半透明底座周围形成光晕，
产品在暗色背景中如悬浮发光，底部光晕柔和扩散
效果：神秘感、悬浮感、仪式感
适用：深色背景创意展示
```

## LT07 — 霓虹彩色光（Neon Accent）
```
描述：粉色或蓝色霓虹灯管作为环境光，从一侧漫射，
产品表面染上淡淡的有色光晕，另一侧保持冷灰本色，
整体氛围前卫且具有街头感
效果：潮流、年轻、有个性
适用：社交媒体系列、品牌形象
```

## LT08 — 阴影叙事（Shadow Play）
```
描述：单一硬光源从一侧打下，产品在另一侧投出拉长的清晰阴影，
阴影本身成为构图的一部分，与实体形成对话
效果：艺术感、故事性、强记忆点
适用：创意广告、品牌调性展示（注意：IG 低光环境下慎用）
```
