# Forbidden Rules — 禁止规则

> 核心原则见 [[core_rules.md]] — 产品不可修改，仅可布置场景。

## ⛔ 禁止生成的视觉

### 类别 1: 错误的产品形态
- ❌ 医疗注射器 / 针筒（syringe）
- ❌ 医院输液管
- ❌ 采血针 / 血糖针
- ❌ 针灸针
- ❌ 订书针 / 文具针

### 类别 2: 错误的材质表现
- ❌ 全透明玻璃管（不是磨砂半透）
- ❌ 金属全包裹外壳（看不到内部）
- ❌ 彩色塑料外壳（除非特指限定版）
- ❌ 橡胶软管质感

### 类别 3: 错误的场景
- ❌ 医院 / 诊所（不是 tattoo 工作室）
- ❌ 手术台
- ❌ 药房柜台
- ❌ 实验室（不要白大褂）

### 类别 4: 错误的使用方式
- ❌ 针刺入皮肤的画面（避免血腥）
- ❌ 有人物脸部的场景（除非手持展示）
- ❌ 大量血迹
- ❌ 脏污使用痕迹（皮肤/桌子上的墨渍可接受）

### 类别 5: 错误的品牌暗示
- ❌ 其他品牌的 logo 或标识
- ❌ 与原图过于相似（避免抄袭竞品图）
- ❌ 非纹身行业的标注文字

## ⚠️ 高危提示词词汇（避免使用）

| 避免 | 因为会触发 |
|------|-----------|
| syringe | 医疗注射器 |
| injection | 打针场景 |
| needle (alone) | 医疗针头 |
| medical | 医院/诊所场景 |
| hospital | 医院背景 |
| blood | 出血场景 |
| doctor | 医生形象 |
| nurse | 护士形象 |
| surgery | 手术场景 |

## ✅ 推荐的替代词

| 替代 | 效果 |
|------|------|
| tattoo cartridge / 纹身墨盒 | 正确的产品名称 |
| precision tip / 精密针尖 | 技术感 |
| gold brass ring / 金色铜环 | 材质准确 |
| frosted housing / 磨砂外壳 | 准确描述透明度 |
| spring mechanism / 弹簧结构 | 内部结构 |
| professional tattooing / 专业纹身 | 行业感 |
