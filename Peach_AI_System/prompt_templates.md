# Prompt Templates — 提示词模板

## 核心原则

产品（Peach 墨盒）是固定不变的实物。Prompt 只描述**场景、光线、机位、布景**，不描述或修改产品本身。

## Prompt 结构

```
[场景/环境] + [构图/机位] + [光线] + [背景] + [画质/技术词]
```

**禁止在 prompt 中描述产品外观。** 产品通过参考图输入，prompt 只负责场景。

## 模板 1: 纯黑悬浮 · 高级感

```
纯黑渐变背景，底部柔和反光形成悬浮倒影，
侧逆光从右后方45°打来，在金属表面勾勒出锐利高光线，
微距镜头，浅景深焦点在前端针尖区域，
商业影棚布光，极致光影层次，超高清画质
```
