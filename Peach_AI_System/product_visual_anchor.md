# Peach Cartridge — 精确产品结构定义

> 所有提示词生成必须基于此结构描述，不可修改产品结构。
> 产品识别特征 = 粉色硅胶心形环 + 绿色塑料 + 白色磨砂外壳 + 顶部粉色塞子

---

## 一、完整结构（从下到上）

```
整体：圆柱形，总长 6.5cm
底部直径：~1.5cm（底部透明塑料因针型不同略有差异）

┌─────────────────────────────┐  ← 顶部（针尖朝下时为底部）
│  粉色塑料塞子               │  1cm 高圆柱
│    └─ 圆心凹陷             │
│      └─ 插入透明圆杆 3mm   │  直径 3mm 透明塑料杆
├─────────────────────────────┤
│  绿色塑料台阶               │  高 2mm
│    └─ 直径比粉色硅胶小 2mm │
├─────────────────────────────┤
│  粉色硅胶环                 │  长 1.5cm
│    ├─ 外层：粉色硅胶        │
│    ├─ 内里：绿色塑料        │
│    └─ 表面：心形凹槽 + PEACH logo
├─────────────────────────────┤
│  白色半透明磨砂外壳         │  主体部分
│    └─ 内部含不锈钢针        │
└─────────────────────────────┘
```

## 二、视觉识别三件套

| 特征 | 颜色 | 材质 | 位置 | 重要性 |
|------|------|------|------|--------|
| **粉色硅胶心形环** | 粉色（外）+ 绿色（内） | 硅胶/塑料 | 中段偏上，1.5cm 长 | ★★★★★ 最强识别 |
| **绿色塑料台阶** | 绿色 | 塑料 | 粉色环上方，2mm 高 | ★★★★☆ |
| **顶部粉色塞子** | 粉色 | 塑料 | 最顶部，1cm 高 | ★★★★☆ |
| **白色磨砂外壳** | 白/半透 | 磨砂塑料 | 下部主体 | ★★★☆☆ |
| **不锈钢针** | 银色 | 不锈钢 | 透明外壳内底部 | ★★★☆☆ |

## 三、各产品线差异

### CON（经典款）
- 粉色硅胶心形环 + 绿色塑料 + 白色磨砂
- 配色：粉绿为主

### COG（高精度款）
- 同上结构
- 配色：灰色/白色为主
- 外壳可能更透明

### AES（PMU 款）
- 同上结构
- 配色：粉色/透明为主
- 外壳半透明更明显

## 四、针型差异（底部）

| 针型 | 针排列 | 底部透明塑料形状 | 举例 |
|------|--------|-----------------|------|
| **RL** (Round Liner) | 圆形排列 | 圆形 | 1003RL, 1403RL |
| **RS** (Round Shader) | 圆形散射 | 圆形，更宽 | 1005RS |
| **M1** (Magnum) | 一字/平行 | 矩形/扁圆 | 1205M1 |
| **CM** (Curved Magnum) | 弧形排列 | 扁圆 | 1205CM |
| **F** (Flat/Feder) | 一字排 | 扁平 | 802F |

针型差异只在底部透明塑料和不锈钢针排列，**上部结构完全一致**。
