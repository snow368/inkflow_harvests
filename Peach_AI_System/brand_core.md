# Brand Core — Peach 墨盒

## 产品定义
- 产品：Peach 纹身墨盒（Peach Tattoo Cartridge Needle）
- 品类：一次性纹身针管墨盒（disposable tattoo cartridge）
- 型号命名：
  - Peach CON（经典款）
  - Peach COG（白色/灰色高精度款）
  - Peach AES（PMU 高精度款）

## 视觉识别特征

### 外壳（Cartridge Housing）
- 主体：白色半透明磨砂塑料 / 白色不透明塑料
- 透光性：磨砂半透，隐约可见内部机械结构（弹簧、针管）
- 质感：细腻磨砂表面，非亮面，非全透

### 接口（Connection / Membrane Base）
- 底座膜：白色橡胶膜 / 透明硅胶膜
- 连接方式：标准 screw 接口（兼容主流纹身机）

### 金属环（Brass / Metal Ring）
- 颜色：金色 / 铜色 / 暗金（Peach 标志性色）
- 位置：墨盒中段或尾部
- 质感：金属拉丝或高光镜面
- 在光线照射下有明显反光，常作为视觉亮点

### 针尖（Needle Tip）
- 材质：银色不锈钢
- 排列：精密整齐排列（圆形/菱形/一字排列取决于针型）
- 针型：RL（圆针）/ RS（散射）/ M1（平针）/ CM（弧针）/ F（排针）
- 针尖在微距下应有高光反射

### 包装标识
- Peach 品牌名
- 规格标注（如 1003RL, 1205M1 等）
- 常用在包装背面或墨盒标签纸上

## 品牌视觉调性
- 专业感（professional clinical）
- 精密感（precision engineering）
- 干净（clean）
- 非医疗感（not medical/hospital）
- 现代工业设计（modern industrial）
