# Visual DNA — 竞品视觉语言提取

从 Cheyenne / BigWasp / BlackClaw / Kwadron / FK Irons / Bishop / Dragonhawk / InkJecta 等 14 个品牌的产品摄影中提取的视觉模式。

## 一、构图

### 单品展示
| 构图类型 | 说明 | 适用场景 |
|---------|------|---------|
| 悬浮居中（Floating Center） | 产品在画面正中央，无接触，背景纯色渐变 | 墨盒 / 针尖 / 小件 |
| 45°斜侧悬浮 | 产品以 45° 角悬浮，有动态感 | 墨盒展示 |
| 微距针尖特写 | 极浅景深，焦点在针尖 | 针尖细节 |
| 侧轮廓 | 正侧面展示墨盒长度和外型 | 产品规格展示 |
| 三合一排列 | 三个产品并排展示，对称构图 | 系列套装 |

### 多件/组合
| 构图类型 | 说明 | 适用场景 |
|---------|------|---------|
| 横向排列 | 多件产品水平排列，有节奏感 | 墨盒套装 |
| 垂直分层 | 产品自上而下排列 | 尺寸对比 |
| 手持展示 | 产品由手指轻轻捏住，展现尺度 | 墨盒大小参照 |
| 布景组合 | 产品 + 包装盒 + 配件组合 | 礼盒/套装 |

## 二、光线

### 常见布光模式
- **侧逆光（Rim Light）** — 光线从侧后方打来，在产品边缘勾勒出高光线，66% 的产品图使用
- **柔光顶光（Soft Top Light）** — 柔光箱从上方 45° 打下，均匀照亮产品，阴影柔和
- **硬质侧光（Hard Side Light）** — 单一强光源从侧面，产生锐利阴影和高对比，适合金属质感
- **匀光箱（Softbox）** — 光线均匀扩散，适合半透明外壳展现内部结构

### 光线参数参考
| 特性 | 常见值 |
|------|--------|
| 方向 | 侧逆光 > 顶光 > 前光 |
| 硬度 | 偏硬（66%）> 柔和（33%） |
| 色温 | 冷（6500K）> 中性 > 暖 |
| 光源数 | 主灯 + 轮廓灯 + 背景灯 |

## 三、背景

### 常见背景风格
| 风格 | 占比 | 特点 |
|------|------|------|
| 纯黑渐变 | 40% | 底部渐变到纯黑，悬浮效果最佳 |
| 纯白无限 | 25% | 干净简洁，适合电商 |
| 深灰工作室 | 15% | 中性百搭，介于黑白之间 |
| 工业金属台 | 10% | 工作台实拍，真实感强 |
| 彩色渐变 | 10% | 品牌色系渐变，如 FK Irons 蓝紫渐变 |

## 四、材质表现

### 标志性材质语言
- **金属**：高光反射锐利不扩散，表面有环境反射
- **磨砂塑料**：在光线下呈现柔和漫反射，无强烈高光
- **半透明外壳**：光线穿透时在边缘形成光晕，内部结构若隐若现
- **橡胶握柄**：哑光质感，吸收光线，与金属形成对比

## 五、色彩

### 常见配色方案
| 方案 | 举例 | 氛围 |
|------|------|------|
| 冷灰 + 品牌色 | 灰黑背景 + 橙色/金色点缀 | 专业科技 |
| 全黑 + 金属银 | 纯黑 + 不锈钢镜面 | 极简高端 |
| 深蓝 + 荧光 | 深蓝背景 + 荧光绿/蓝灯效 | 电竞/现代 |
| 暖金 + 深褐 | 金色配件 + 皮革质感 | 复古奢华 |

## 六、色系分布
| 主色调 | 占比 | 常见品牌 |
|--------|------|---------|

| 白/灰 | 23% | Bishop, Cheyenne |
