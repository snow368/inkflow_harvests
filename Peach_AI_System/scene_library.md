# Scene Library — 场景库

标准化的拍摄场景配置，每个场景 = 构图 + 光线 + 背景 + 氛围的组合。

## SC01 — 纯黑悬浮 · 单品展示

```
构图：  悬浮居中（floating center）
机位：  45° 斜侧 / 平视
光线：  侧逆光 + 补光
背景：  纯黑渐变（底部中灰 → 顶部纯黑）
材质：  底部微弱反光形成倒影
焦点：  墨盒中部 / 铜环
氛围：  极简、高端、精密
代表作： FK Irons 产品图
```

## SC02 — 纯白无限 · 电商展示

材质：  白色反光形成漂浮感
焦点：  整体均匀

## SC20 — Exploded View（爆炸分解图）

```
构图：  产品分解为部件沿轴线排列，部件间有小间距
光线：  均匀柔光，各部件独立均匀照亮
背景：  纯白 / 浅灰
关键：  按组装顺序排列，带虚线或轨迹暗示更佳
色彩：  真实材质色
机位：  45° 斜侧（最佳）/ 正侧
氛围：  技术解析、工艺展示、透明品质
代表作：  耳机 / 机械表分解图
```

## SC21 — Macro Close-up（超微距）

```
构图：  极近距离，画面只展示产品某个局部
光线：  环形微距灯 / 侧硬光
背景：  完全虚化（焦外成像）
景深：  < 1mm，仅几根针尖在焦内
放大倍率： > 1:1
焦点：  针尖切面 / 铜环纹理 / 外壳磨砂颗粒
氛围：  极致细节、显微美学、精密工业
```
